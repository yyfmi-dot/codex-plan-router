# Codex Plan Router · public beta

Save edits and quit CC Switch once, then open **Install.command**. The installer UI currently uses Chinese. See the English [project README](https://github.com/yyfmi-dot/codex-plan-router#install) for the complete walkthrough, requirements, recovery steps, and limitations. 中文说明见同目录「给同事的说明.md」。

Each person uses their own authorized credentials. This archive contains no accounts, keys, or conversation history. API standby can incur charges. The App is ad-hoc signed, without Apple notarization. Use macOS's standard approval UI; do not disable Gatekeeper.

MIT project code; upstream notices are included. Current model data is downloaded locally on first startup. Failed updates retain the last valid directory. Newer models may require a successful update.
