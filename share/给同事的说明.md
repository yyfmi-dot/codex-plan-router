# Codex Plan Router 0.3.0-beta.1 · CC Switch 联动测试版

适用：Apple Silicon、macOS 12+、Python 3.9+、Codex CLI 0.167+。Intel 配套 App 尚未构建。本包不含任何人的账号或密钥。

1. 在原 CC Switch 保存编辑，并从菜单退出一次。
2. 解压后双击「安装.command」。安装器保留原版，在 ~/Applications 安装联动版，继续使用本机现有 CC Switch 账号库，并通过 Codex 原生命令安装插件。
3. 本机设置页会自动显示有效账号和官方 API Key，无需重新登录。过期账号在 CC Switch 重新认证；新增/删除账号约 5 秒同步。
4. 选择实际支持的模型，点「启用路由并统一历史」，再重启 Codex 一次。以后打开联动版 CC Switch；插件后台启动时也会尝试打开它。CC Switch 的 Codex 使用直连模式。

此测试 App 仅有 ad-hoc 签名，尚无 Developer ID 签名和 Apple 公证，首次运行可能需要本人在 macOS 隐私与安全性中按系统提示允许。安装器不关闭系统安全保护。配套版不要更新成普通 CC Switch，否则桥接会消失；后续用配套包升级。

Plan 失败后尝试其他可用 Plan，再使用按用量计费的 API；冷却后返回 Plan。API Key 可能共享组织额度。已使用真实耗尽账号验证 Plan 到 Plan/API 的自动回退；自然额度重置恢复尚未观察，模拟调度、真实回退和全新 macOS 虚拟机安装检查分开报告。

历史统一为 custom 分组。旧会话先备份，活动会话待关闭后迁移；跨账号加密推理上下文可能不兼容。CC Switch 停止后来源缓存最多保留 30 秒，随后路由不可用；重新打开联动版后自动恢复。

停用时先在设置页恢复原配置和原官方会话分组，关闭活动会话后重试剩余还原，再运行卸载。仅删除 App 或禁用插件不会停止后台服务。原 CC Switch App 和账号库都保留，恢复后可改回原版。

不用配套 App、独立登录：运行 python3 install.py --plugin-only。改变已有安装的凭据来源前先恢复路由。

模型列表以 MIT 许可的 CLIProxyAPI 内置目录启动；首次启动即尝试更新，此后每 3 小时检查更新，也可点击「更新可选模型」。有效目录保存在本机，更新失败继续使用上次版本。启用时 CC Switch 会将包含多个模型的目录交给 Codex，之后用户可在 Codex 中切换模型；账号和 Plan/API 切换保持请求模型。gpt-6.2-sol 等新模型需要成功更新目录后才可选择。真实推理验证与验收边界见项目 docs/verification.md。
