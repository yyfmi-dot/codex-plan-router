# v0.3.0-beta.1 · first public beta / 首个公开测试版

Local Codex routing with CC Switch integration, user-selected models, API standby, and backed-up conversation-provider migration. Every teammate installs their own copy with their own authorized accounts.

联动本机 CC Switch，保留用户选择的模型，提供 API 备用和带备份的会话分组统一。每位同事独立安装并使用自己的授权账号。

- Download **Codex-Plan-Router-macOS-0.3.0-beta.1-share.zip** for the companion App, plugin, and installer. The smaller plugin ZIP alone does not include the App.
- Requires Apple Silicon, macOS 12+, Python 3.9+, and Codex CLI 0.167+. Settings currently use Chinese.
- Ad-hoc signed; not Apple notarized. Keep the original CC Switch, save edits, and quit it once before installation. Restore routing before uninstalling.
- A MIT-licensed baseline catalog is bundled. The latest directory downloads locally on first startup; new models require a successful update.
- API standby is billable; credentials can share account/organization limits. This does not increase entitlements or guarantee continuity.
- Unit tests, native client checks, and simulated failover are distinct. The earlier local prototype completed real Plan/API same-thread inference; actual quota-exhaustion end-to-end acceptance remains open.

See the bilingual README, SECURITY.md, THIRD_PARTY_NOTICES.md, and docs/verification.md before installation. SHA256SUMS.txt covers both release ZIPs. No credentials, user profiles, or conversation data are distributed.
