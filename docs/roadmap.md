# Roadmap

The first release is a public beta for local, individual macOS workflows.

## Release acceptance

- [x] Account/key discovery, credential-generation ownership, and delegated configuration writer
- [x] User model choice and gpt-6.2-sol Plan/API canary in the local prototype
- [x] Native model-picker and plugin-loader checks with CLI 0.167 / 0.169
- [x] Restore paths, native writer leases, catalog rollback, and redacted source audit
- [x] Real already-exhausted Plan to Plan/API failover with authorized credentials
- [ ] Natural quota depletion and reset recovery observation
- [x] Published installer on a fresh Apple Silicon macOS 15.8.2 hosted VM (18 checks)
- [ ] Browser quarantine approval and interactive first login on a physical Mac
- [ ] Developer ID signing and Apple notarization
- [ ] English settings UI and localized diagnostics
- [ ] Intel macOS companion, then evaluate other desktop platforms

## Next product work

1. Per-account/project allowlists and explicit routing-policy visibility.
2. Clear active credential/reason diagnostics without exposing secrets.
3. Opt-in API spending controls backed by measurable attribution.
4. Reduce companion maintenance through upstream bridge adoption when feasible.
5. Add compatibility fixtures as upstream Codex and CC Switch evolve.

These are priorities, not delivery dates. No central subscription pool, key resale service, or cross-account quota guarantee is planned.
